# Excel Data Analysis Practice

## Project Overview
This repository contains Excel practice exercises focused on data lookup, data retrieval, and summarization using employee salary data.

## Skills Practiced
- VLOOKUP for retrieving employee information
- XLOOKUP for flexible data retrieval
- Pivot Tables for summarizing salary data
- Department-wise salary analysis
- Organizing and interpreting tabular data

## Worksheets
1. **VLOOKUP Practice:** Retrieve employee details using lookup formulas.
2. **XLOOKUP:** Retrieve employee salaries, names, and departments.
3. **Pivot Table:** Summarize salary information using Pivot Tables.

## Objective
To strengthen practical Excel skills relevant to Data Analyst roles, including data retrieval, summarization, and basic business reporting.

## Tools
- Microsoft Excel
